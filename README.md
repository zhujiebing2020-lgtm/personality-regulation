# 多主体互动中的人格调度

**自主性、资源配置与动态更新**  
*Personality Regulation in Multi-Agent Interaction: Autonomy, Resource Allocation, and Dynamic Updating*

朱洁冰 / Jiebing Zhu · 理论框架修订稿 V3 · 2026-09-30

[在线阅读全文 / Read the paper](paper.md) · [PDF](https://z-jb.com/research/papers/personality-regulation-v3.pdf) · [个人研究主页 / Research profile](https://z-jb.com/research)

本文提出一个多主体互动中的人格调度框架，连接主体状态、自我觉察与授权边界，共同域中的同意质量与权力不对称，以及策略选择、成本流向和多时间尺度更新。包含案例卡编码、变量操作化、七项可被反驳的命题与分阶段验证设计。

This theoretical framework connects agent state, self-awareness and authorization boundaries with consent quality, power asymmetry, strategy selection, cost flows and updating across interactions. It includes case coding, operationalizations, seven falsifiable propositions and a staged validation design.

**研究状态：**理论框架修订稿，尚未进行经验验证。示例为假设情境；预测效度、跨情境适用性与增量价值仍待独立数据检验。  
**Status:** Theoretical framework draft. Empirical validation remains to be conducted; examples are hypothetical.
